# Waguri Framework website

Responsive React, TypeScript, Vite and Tailwind CSS website for the Waguri Framework project.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev`. Run `npm run build` to type-check and create a production build in `dist/`.

## Project status

This repository contains the website only. It has no Waguri Python package, backend, implemented validation API, model adapter, benchmark suite or verified license information. The Playground is deterministic sample output and does not call a model. Framework APIs shown on the website are conceptual and marked as proposed.
